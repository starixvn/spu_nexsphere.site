## Next.js App Router Course - Starter

# Install nvm to manage Node.js versions (if not already installed)
Link: https://github.com/coreybutler/nvm-windows/releases

# Update node version to v20.16.0
nvm install 20.16.0 
nvm use 20.16.0 
nvm alias default 20.16.0

# Install pnpm:
npm install -g pnpm

# Install node-module:
pnpm i

# Run app
pnpm dev
